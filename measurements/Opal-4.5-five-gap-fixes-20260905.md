## Five improvements

1. **Export only the required DLL contract.** Replace 4,603 broad exports with Windhawk's five implemented lifecycle callbacks, its writable `InternalWhModPtr`, and XAML's `DllGetClassObject`. Check actual PE tables, initialization and writable data. Preserve an explicit legacy export option and isolated candidate builds. Frozen equal-source builds show 33.8% fewer file bytes and 472 KiB less image space; this is not a measured working-set saving.
2. **Avoid unchanged UI work.** Copy settings only after a fresh metrics snapshot exists; reuse unchanged mirror foreground colors and accessibility names; avoid redundant panel text/visibility writes. Preserve sampling cadence, graphs, temperature fallback and visible features. Compiled production-function tests exercise unchanged and changed values, alerts, colors and null/non-solid brushes.
3. **Handle partial media-provider data.** Reject missing properties/playback safely and clear stale controls; preserve valid metadata/transport controls when the timeline interface is absent, with seeking disabled; default missing transport capabilities to disabled. A thrown provider error still follows existing retry behavior. These guards are not attributed as a fix for the observed CloudStore crash.
4. **Let Explorer own taskbar-module loading.** Remove speculative synchronous packaged Taskbar.View loading and its 15 x 100 ms retry loop. Retain existing initialization, natural module-load callback and bounded fallback polling. This removes early startup interference; crash recurrence must be checked independently. Prior benchmark/restoration identity fixes remain in place.
5. **Make latency exports identifiable.** Add PID, process birth, report-export time and collection epoch on the existing Copy hardware report action, with strict parser validation and legacy compatibility. Hot-path timing collection is unchanged. Actual user interaction evidence is distinct from the executable producer/parser fixture; metadata alone does not verify an installed build or create a latency SLA.

Real taskbar interaction is not targetable through the available desktop tool. Maxwell was asked whether he can perform brief normal interactions after installation. Automated collector/parser fixtures must not be presented as real panel/media latency.
